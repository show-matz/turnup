
## 設定
### 見出しにおける自動リンク
<!-- autolink: [config:term-link-in-header](#見出しにおける自動リンク) -->
<!-- autolink: [term-link-in-header](#見出しにおける自動リンク) -->

　[$$](#キーワードへの自動リンク)機能は、デフォルトでは見出し文字列
（正確には[$$](#見出し)および[$$](#図と表のタイトル)）
には適用されません。これは見出し内にリンクを生成するとうるさくなることや、見出しに存在する
文字列は通常そのセクションの本文にも存在することが理由です。

　この挙動を変えたい場合、以下の行を文書内に記載してください。見出し文字列内でも自動
リンクが行なわれるようになります。

```markdown
  <!-- config:term-link-in-header -->
```

### 見出しの自動ナンバリング
<!-- autolink: [config:header-numbering](#見出しの自動ナンバリング) -->
<!-- autolink: [header-numbering](#見出しの自動ナンバリング) -->

　見出しに自動的に番号付けを行なうことができます。この機能を有効化するには、以下の設定を
文書内に記載します。

```markdown
  <!-- config:header-numbering -->
```

　これにより、1.1.1. 形式で見出しに自動的に番号が付与されます{{fn:番号付けの書式は今のところこれだけで、選択はできません。}}。
この番号を付与する見出しのレベルを限定したい場合、以下のように記載します。この例では、
見出しレベル２〜４の合計３レベルで採番されます。
この場合、見出しレベル1、および 5 以降には番号付けは適用されません。

```markdown
  <!-- config:header-numbering 2 4 -->
```

### 図表のナンバリング単位
<!-- autolink: [config:entity-numbering-depth](#図表のナンバリング単位) -->
<!-- autolink: [entity-numbering-depth](#図表のナンバリング単位) -->

　[図表タイトル](#図と表のタイトル)、および[図表一覧生成](#図表一覧の生成)に適用される番号付けの
規則を設定することができます。これには、以下のように記述します。この設定を省略した場合のデフォルト
値は 0 です。

```markdown
  <!-- config:entity-numbering-depth 1 -->
```

　0 が指定された場合、図と表それぞれについて、文書全体を通して 1 から始まる連番が付与されます。
つまり、図であれば Figure.1 xxxxx、Figure.2 yyyyy といった要領です（表の場合は Table.1 zzzzz）
となります。

　1 以上を指定した場合、「[](#見出しの自動ナンバリング)」で指定した番号付け対象の見出しのうち、
先頭から指定した数のレベルを単位として 1 から始まる番号付けを行ないます。こう書くとわかりにくい
ですが、たとえば以下のようにした場合、

```markdown
  <!-- config:header-numbering 2 4 -->
  <!-- config:entity-numbering-depth 2 -->
```

まず、ナンバリングをする見出しはレベル 2,3,4 です。そして、図表については見出しレベルの 2,3 が一致
するものについて 1 から連番で番号付けをし、これらの見出しレベルが変化するとまた 1 からナンバリングが
始まります。なお、この場合は図であれば Figure.1.2-1 xxxxxx といった書式になります。

　version 0.835 より、この設定において数値の他に `off` が指定可能になりました。 `off` を指定すると、
図表の自動ナンバリングが無効化されます。これは、図表タイトルに図表番号含めることで手動での番号付けを
行ないたい場合に対応するものです。

### スタイルシートの埋め込み
<!-- autolink: [config:embed-stylesheet](#スタイルシートの埋め込み) -->
<!-- autolink: [embed-stylesheet](#スタイルシートの埋め込み) -->

　[スタイルシートの指定](#文書タイトルとスタイルシートの指定)は、デフォルトでは
スタイルシートの参照が出力されるだけですが、以下の設定が文書内に記述されていると、
出力 HTML の内部にスタイルシートの内容を埋め込むようになります。

```markdown
  <!-- config:embed-stylesheet -->
```

　これによって、以下のように埋め込みが行なわれます。

~~~html
<html>
<header>
    <meta http-equiv="Content-Type" content="text/html; charset=utf-8">
    <meta http-equiv="Content-Style-Type" content="text/css">
    <title>document title</title>
  <style>
  <!--
    :
    : （この部分に CSS が埋め込まれる）
    :
  -->
  </style>
</header>
~~~

　この設定を有効にしてスタイルシートの埋め込みを行なう場合、turnup の実行時点で
指定されたスタイルシートのファイルが存在していなければなりません（当たり前ですが）。

そのまま出力するようになります。

### MathJax 利用の明示的宣言
<!-- autolink: [config:use-mathjax](#MathJax 利用の明示的宣言) -->
<!-- autolink: [use-mathjax](#MathJax 利用の明示的宣言) -->

　turnup は基本的に MathJax の利用を自動的に検出して必要な `<script>` タグを出力 HTML のヘッダに挿入します
が、これがうまく動作しない場合があります{{fn:実際には、実際には不要なのに必要と認識することの方が多そうですけど。}}。
そのような場合、以下の設定を記述してください。強制的に MathJax スクリプトへの参照を挿入します。

```markdown
  <!-- config:use-mathjax -->
```

### 脚注のプレフィクス設定
<!-- autolink: [config:footnote-prefix](#脚注のプレフィクス設定) -->
<!-- autolink: [footnote-prefix](#脚注のプレフィクス設定) -->

　脚注で使用されるリンクは通常 1 から始まる連番で表示されますが、footnote-prefix 設定を使用
することによってリンクに任意のプレフィクスを表示させることができます。たとえば以下のようにする
ことで、

```markdown
  <!-- config:footnote-prefix  JP  '訳注 ' -->
```

タグ `JP` を使う脚注（つまり `{{fn(JP):...}}` という形式）で表示されるリンクが `訳注 1` といった
文字列になります。この footnote-prefix 設定は複数のタグに対して指定することができます。

### HTML の直接出力抑止
<!-- autolink: [--safe オプション](#HTML の直接出力抑止) -->

　入力となる markdown データの内容を直接制御できない場合、 _HTML マクロ関数や 
raw フィルタの使用を許可するのは危険かもしれません。そのような場合、--safe オプション
を使用するとよいでしょう。

```sh
 turnup  --safe  input.md  > output.html
```

　--safe オプションをつけて turnup を起動すると、出力 HTML を直接指定する
機能は効力を失います。つまり、raw フィルタは単純な pre ブロックとなり、_HTML マクロ
関数はその内容に含まれるタグを全てエスケープして出力します。

### ハッシュ値生成に対する salt 指定
<!-- autolink: [--salt オプション](#ハッシュ値生成に対する salt 指定) -->

　turnup では、主にページ内リンクのためのアンカーにハッシュ値を生成して使用
しています。起動パラメータ --salt を使用することにより、このハッシュ値生成にソルト
を指定することができます。以下の要領で、 `--salt=` に続けて任意の文字列を指定して
ください。

```sh
 turnup  --salt=VWXYZ  input.md  > output.html
```

　turnup におけるハッシュ値生成はアンカーの生成だけが目的のため、ここで指定
するソルトはセキュリティとは何の関係もありません。このオプションは、「その出力ファイル
がどのソルト指定によって作成されたかを識別するため」に使用することを想定しています。
